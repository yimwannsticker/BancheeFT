# บัญชีคู่รัก 💸

เว็บแอพสำหรับคนสองคน (เช่น เตย กับ เฟิร์ส) บันทึกว่าใครจ่ายอะไรแทนกัน โดยพิมพ์ประโยคสั้นๆ ในช่องแชท แล้วสรุปยอดปลายเดือนให้อัตโนมัติว่าใครต้องโอนให้ใครเท่าไหร่

ไม่มีระบบสมัครสมาชิก ไม่มีค่าใช้จ่าย ใช้ห้องเดียวตายตัวสำหรับสองคน — เปิดเว็บนี้จากอุปกรณ์ไหนก็เข้าห้องเดียวกันเสมอ ไม่ต้องแชร์ลิงก์พิเศษ

## ตัวอย่างการใช้งาน

พิมพ์ในช่องแชทแล้วกด Enter:

| พิมพ์ | ระบบเข้าใจว่า |
|---|---|
| `ส้มตำ 60` | ฉัน (เจ้าของเครื่อง) จ่าย 60 บาท หารครึ่ง |
| `เตย จ่าย ส้มตำ 60` | เตยจ่าย 60 บาท หารครึ่ง → เฟิร์สติดเตย 30 |
| `เตย จ่าย แท็กซี่ 120 แทน` | เตยจ่ายแทนทั้งหมด → เฟิร์สติดเตยเต็ม 120 |
| `เตย จ่าย เสื้อ 500 ส่วนตัว` | บันทึกไว้เฉยๆ ไม่นำมาคิดยอด |
| `เฟิร์ส เคลียร์ 500` หรือ `เฟิร์ส โอนให้ เตย 500` | บันทึกว่าเฟิร์สโอนเงินคืนแล้ว 500 |

ถ้าพิมพ์แล้วระบบไม่เข้าใจ (เช่น สะกดชื่อผิด ไม่มีตัวเลข) ระบบจะถามกลับแทนการเดา

## วิธีตั้งค่า (สำหรับคนที่ไม่ใช่โปรแกรมเมอร์ ทำตามทีละขั้นได้เลย)

ใช้เวลาประมาณ 15-20 นาที ทำครั้งเดียว ฟรี 100%

### ขั้นที่ 1: สร้างโปรเจกต์ Supabase (ที่เก็บข้อมูล)

1. ไปที่ [supabase.com](https://supabase.com) แล้วสมัคร/เข้าสู่ระบบด้วย GitHub หรืออีเมล
2. กด **New Project** ตั้งชื่ออะไรก็ได้ (เช่น `bancheeft`) ตั้งรหัสผ่านฐานข้อมูลเก็บไว้ (เผื่อใช้ทีหลัง) เลือก region ใกล้ๆ เช่น Singapore
3. รอสักครู่ให้โปรเจกต์สร้างเสร็จ (~1-2 นาที)
4. ไปที่เมนู **SQL Editor** (ไอคอนรูปเทอร์มินัลด้านซ้าย) กด **New query**
5. เปิดไฟล์ [`supabase/schema.sql`](./supabase/schema.sql) ในโปรเจกต์นี้ คัดลอกทั้งหมด วางในช่อง SQL Editor แล้วกด **Run**
   - ถ้าขึ้น "Success. No rows returned" แปลว่าสำเร็จ
6. ไปที่เมนู **Project Settings** (รูปเฟือง) → **API**
   - คัดลอกค่า **Project URL** (หน้าตาเหมือน `https://xxxxxxxxxxxx.supabase.co`)
   - คัดลอกค่า **anon public** key (สตริงยาวๆ)
   - เก็บสองค่านี้ไว้ ใช้ในขั้นตอนถัดไป

### ขั้นที่ 2: ตั้งค่าโปรเจกต์ในเครื่อง

1. ติดตั้ง [Node.js](https://nodejs.org) (เวอร์ชัน 18 ขึ้นไป) ถ้ายังไม่มี
2. เปิด terminal ในโฟลเดอร์โปรเจกต์นี้ แล้วรัน:
   ```bash
   npm install
   ```
3. คัดลอกไฟล์ `.env.example` เป็น `.env` แล้วใส่ค่าจาก Supabase ที่คัดลอกไว้:
   ```bash
   cp .env.example .env
   ```
   เปิดไฟล์ `.env` แก้เป็น:
   ```
   VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=ค่า-anon-key-ที่คัดลอกมา
   ```
4. ทดสอบรันในเครื่อง:
   ```bash
   npm run dev
   ```
   เปิดลิงก์ที่ขึ้นมา (เช่น `http://localhost:5173`) ในเบราว์เซอร์ ควรใช้งานได้แล้ว

### ขั้นที่ 3: Deploy ขึ้น Cloudflare Pages (ฟรี)

1. Push โค้ดโปรเจกต์นี้ขึ้น GitHub (repo ส่วนตัวก็ได้)
2. ไปที่ [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create application** → แท็บ **Pages** → **Connect to Git**
3. เลือก repository นี้
4. ตั้งค่า Build:
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. ก่อนกด Deploy ให้ไปที่ **Environment variables** ใส่ 2 ตัวแปรเดียวกับไฟล์ `.env`:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
6. กด **Save and Deploy** รอสักครู่ จะได้ลิงก์เว็บ เช่น `https://bancheeft.pages.dev`

### ขั้นที่ 4: เริ่มใช้งาน

1. ส่งลิงก์เว็บที่ได้ (เช่น `https://bancheeft99.xxx.workers.dev`) ให้อีกคนผ่านแชทที่ไว้ใจกัน — **เปิดลิงก์เดียวกันนี้จากอุปกรณ์ไหนก็ได้ เข้าห้องเดียวกันเสมอ** ไม่มี `?room=` ต่อท้ายให้สับสน
2. ทั้งสองคนเปิดลิงก์ → เลือกว่าเครื่องนี้เป็นของใคร → เริ่มพิมพ์บันทึกรายการได้เลย
3. อยากติดตั้งเป็นแอพบนหน้าจอโฮม: เปิดลิงก์ในเบราว์เซอร์มือถือ (Safari/Chrome) แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" / "Add to Home Screen" — ไอคอนที่ได้จะเปิดเข้าห้องเดียวกันเสมอ เพราะห้องผูกกับตัวเว็บเอง ไม่ได้ผูกกับลิงก์ที่เปิดตอนติดตั้ง
4. แก้ชื่อ "เตย"/"เฟิร์ส" เป็นชื่อจริงได้ที่แท็บ **ตั้งค่า**

## ข้อควรรู้เรื่องความปลอดภัย

- แอพนี้ไม่มีระบบสมัครสมาชิก/รหัสผ่าน ความเป็นส่วนตัวขึ้นอยู่กับการไม่แชร์ลิงก์เว็บให้คนอื่น
- เหมาะกับการใช้กันเองสองคนแบบไม่เป็นทางการ **ไม่เหมาะกับข้อมูลอ่อนไหวระดับธนาคาร**
- ห้องเดียวตายตัวถูกกำหนดไว้ใน `ROOM_ID` (`src/lib/room.ts`) ถ้าอยากเริ่มห้องใหม่ (ข้อมูลเก่าจะไม่ติดมา) แก้ค่านี้เป็นรหัสใหม่แล้ว deploy ใหม่

## รันเทส

```bash
npm test
```

ครอบคลุม parser (แปลงข้อความ → รายการ) และตัวคำนวณยอดคงเหลือ

## โครงสร้างโค้ดหลัก

```
src/
  lib/
    parser.ts      # แปลงข้อความแชท → รายการ (rule-based ไม่ใช้ LLM)
    balance.ts      # คำนวณยอดค้าง/สรุปเดือน
    money.ts         # แปลงหน่วยสตางค์ <-> บาท
    api.ts           # เรียก Supabase (CRUD entries/rooms)
    room.ts          # ROOM_ID ห้องตายตัว + ตัวตนอุปกรณ์ (localStorage)
  pages/
    ChatPage.tsx      # หน้าแชทหลัก
    TablePage.tsx     # ตารางรายการ + export CSV
    SummaryPage.tsx   # สรุปยอด + เคลียร์ยอด
    SettingsPage.tsx  # ตั้งชื่อ/สลับตัวตน/ถังขยะ
supabase/schema.sql # โครงสร้างฐานข้อมูล
```

## แผนระยะที่ 2 (ยังไม่ได้ทำ)

โครงสร้างข้อมูลออกแบบไว้ให้รองรับได้โดยไม่ต้องรื้อของเดิม:

- **Line bot**: ส่งข้อความเข้า webhook แล้วเรียก `parseMessage()` ฟังก์ชันเดียวกับในแอพ จากนั้น insert เข้า Supabase ตรงๆ
- **หารไม่ใช่ 50/50** (เช่น 70/30): เพิ่มคอลัมน์ `split_ratio` ในตาราง `entries` (เช่น เก็บเป็นเศษส่วน `70` หมายถึงฝั่งอีกคนติด 70% ของยอด) แล้วปรับ `entryContribution()` ใน `balance.ts` ให้อ่านค่านี้แทนค่าคงที่ 50%
